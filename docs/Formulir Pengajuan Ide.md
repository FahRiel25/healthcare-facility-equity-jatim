| Judul ide | Analisis dan Klasifikasi Tingkat Kecukupan Fasilitas Kesehatan di Kabupaten/Kota Provinsi Jawa Timur. |
| SDG dan target yang dipilih | Proyek ini berfokus utama pada Goal 3 – Good Health and Well-Being (Kehidupan Sehat dan Sejahtera), khususnya target 3.8 mengenai pencapaian cakupan kesehatan universal dan akses terhadap pelayanan kesehatan esensial yang berkualitas. |
| Masalah nyata yang diangkat | Ketersediaan fasilitas kesehatan dan tenaga kesehatan berpotensi memiliki distribusi yang berbeda antarwilayah di Jawa Timur. Perbedaan jumlah penduduk dan karakteristik wilayah dapat memengaruhi tingkat kecukupan fasilitas kesehatan. Kondisi tersebut menjadi permasalahan dalam memahami pemerataan ketersediaan fasilitas kesehatan antar kabupaten/kota. Oleh karena itu, diperlukan analisis berbasis data untuk mengklasifikasikan tingkat kecukupan fasilitas kesehatan serta memberikan gambaran mengenai kondisi masing-masing wilayah. |
| Tugas ML (Target dan jenis tugas) | - Supervised Learning berupa klasifikasi multikelas (Multiclass Classification). <br/><br/> - Target klasifikasi berupa tingkat kecukupan fasilitas kesehatan yang terdiri atas tiga kelas, yaitu Rendah, Sedang, dan Tinggi. <br/><br/> - Klasifikasi dilakukan terhadap data kabupaten/kota di Provinsi Jawa Timur berdasarkan indikator fasilitas kesehatan, tenaga kesehatan, dan karakteristik wilayah. |
| Objective dan metrik utama | Model dioptimasi untuk meminimalkan kesalahan klasifikasi menggunakan fungsi loss yang sesuai dengan masing-masing model. Performa akhir dievaluasi menggunakan **Macro F1-score sebagai metrik utama**, serta Accuracy, Precision, Recall, dan Confusion Matrix sebagai metrik pendukung. Macro F1-score digunakan untuk memperhatikan performa klasifikasi pada setiap kelas secara seimbang. |

| Rencana tiga model (baseline / advanced / deep learning) | - **Decision Tree Classifier** sebagai model baseline yang memiliki interpretabilitas tinggi dan dapat menghasilkan aturan klasifikasi yang mudah dipahami. <br/><br/> - **Random Forest Classifier** sebagai model advanced machine learning yang menggunakan ensemble beberapa decision tree untuk meningkatkan kemampuan klasifikasi dan mengurangi risiko overfitting. <br/><br/> - **Multilayer Perceptron (MLP)** sebagai model deep learning dengan minimal dua hidden layer, menggunakan fungsi aktivasi ReLU dan Softmax pada output untuk klasifikasi tiga kelas. Optimasi dilakukan melalui pengaturan hyperparameter, regularisasi, serta evaluasi training dan validation. |
| Risiko dan pertimbangan etika (bias, privasi) | Risiko utama meliputi ketidaklengkapan data fasilitas kesehatan dan tenaga kesehatan antarwilayah, ketidakseimbangan distribusi kelas, serta potensi bias akibat perbedaan karakteristik kabupaten dan kota. Penentuan label kecukupan perlu menggunakan indikator dan kriteria yang transparan agar tidak menghasilkan klasifikasi yang menyesatkan. Data yang digunakan berupa data agregat wilayah sehingga tidak melibatkan identitas pribadi pasien. Hasil klasifikasi tidak digunakan sebagai penilaian langsung terhadap kualitas pelayanan kesehatan, melainkan sebagai informasi pendukung analisis pemerataan fasilitas kesehatan. |
